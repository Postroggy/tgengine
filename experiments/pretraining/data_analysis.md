# 跨域 CTDG 数据分析：预训练设计基础（2026-06-30）

## 动机

为预训练目标设计提供数据基础。核心问题：
1. 我们的 CTDG 数据集有多异构？
2. 哪些信号是跨域可迁移的？
3. co-occurrence 作为"强监督信号"（DyGFormer 假设）是否成立？

- 重复交互率从 0%（BitcoinAlpha）到 93%（enron）

## 信号分析：哪些跨域可迁移？

### 1. Co-occurrence（共同邻居）— ❌ 对二部图无效

| Dataset | Co-oc AUC | 说明 |
|---------|-----------|------|
| uci | 0.509 | 同构图，弱信号 |
| enron | 0.643 | 同构图，中等信号 |
| BitcoinAlpha | 0.506 | 同构图，弱信号 |
| wikipedia | 0.500 | **二部图，0 共同邻居** |
| reddit | 0.500 | **二部图，0 共同邻居** |
| lastfm | 0.500 | **二部图，0 共同邻居** |
| mooc | 0.500 | **二部图，0 共同邻居** |

**结论**：co-occurrence 在二部图上完全失效（src 和 dst 在不同分区，没有共同邻居）。DyGFormer 的"co-occurrence 强监督"假设只在同构图上成立。**不能作为跨域统一信号。**

### 2. 重复交互（"以往交互多的未来也多"）— ⚠️ 信号中等但方差大

| Dataset | Repeat AUC | Count AUC | Repeat% |
|---------|-----------|-----------|---------|
| reddit | **0.834** | 0.841 | 71.1% |
| wikipedia | 0.705 | 0.705 | 42.2% |
| enron | 0.677 | 0.687 | 47.5% |
| lastfm | 0.633 | 0.642 | 41.6% |
| uci | 0.549 | 0.549 | 12.1% |
| BitcoinAlpha | 0.496 | 0.495 | 0.0% |
| mooc | 0.443 | 0.447 | 10.2% |

**信号一致性**：mean=0.620, std=0.124

**结论**：用户的洞察"以往交互多的未来也多"在**密集图**上成立（reddit AUC 0.83），但在**稀疏图**上失效（BitcoinAlpha/mooc AUC≈0.5）。信号强度与图密度/重复率强相关。**不是可靠的跨域统一信号。**

### 3. 度特征 — ❌ 无信号

src degree / dst degree AUC = 0.50（所有数据集）。随机负采样下，节点度无法区分正负样本。

## 对预训练设计的启示

### 发现 1：没有单一信号是跨域通用的

- co-occurrence 对二部图失效
- 重复交互对稀疏图失效
- 度特征对随机负采样失效

**含义**：预训练目标不能依赖单一信号。link prediction BCE 的优势在于让模型**学习组合多种信号**，而非假设某个信号固定有效。

### 发现 2：数据集异质性比预期更大

- 同构 vs 二部图结构差异
- 重复交互率 0%~93%
- 图密度 55~1157 avg degree

**含义**：跨域预训练需要处理结构异质性。AnyGraph 的 MoE 方案（不同专家处理不同域）可能是必要的。

### 发现 3：edge feature 维度统一但语义不同

所有 DyGLib 系列数据集 d_edge=172（LIAR 编码），但语义完全不同（wikipedia 是文本特征，enron 是邮件特征）。

**含义**：不能直接拼接 edge feature。需要 dataset-specific projection 或结构特征统一化。

## 推荐预训练方向

基于数据分析，**link prediction BCE 仍然是最稳健的预训练目标**：
- 不依赖单一信号
- 模型自动学习各域的有效信号组合
- 直接对齐 eval

跨域处理推荐**结构特征统一化**（不用 node ID / domain-specific feature），但需注意：
- 不用 co-occurrence 作为强信号（二部图失效）
- 用 domain-agnostic 特征：edge feat proj + 时间编码（RoPE Δt）+ recency + interaction count
